# New Deck Skill

## Purpose
Quickly scaffold a new UW-branded presentation.

## Usage
```bash
claude code /uw-slides:new-deck my-presentation
```

## Generated Structure
```
my-presentation/
├── content/
│   ├── 01-title.md
│   ├── 02-overview.md
│   └── 03-conclusion.md
├── assets/
├── order.txt
├── .gitignore
└── README.md
```

Creates 3 sample slides to get you started.

See `README.md` for complete documentation.
