# University of Washington Brand Guidelines for Slide Decks

## Official Resources
- UW Brand Portal: https://www.washington.edu/brand/
- Color Palette: https://www.washington.edu/brand/web-colors/
- Typography: https://www.washington.edu/brand/fonts/

## Core Brand Elements

### Colors
**Primary:**
- UW Purple: #4b2e83 (spirit-purple), #32006e (husky-purple)
- UW Gold: #ffc700 (spirit-gold), #e8e3d3 (husky-gold-web)

### Typography
- **Encode Sans** (100-900) — Headlines, titles
- **Open Sans** (300-700) — Body text, subtitles

### Slide Requirements
- Gold accent bar (8px) on every slide
- Minimum font size: 24px at 1920×1080
- W mark logo: white on dark backgrounds
- NSF logo: always full-color (never invert)

## WCAG 2.1 AA Compliance Required
- Contrast: 4.5:1 for text, 3:1 for large text
- Alt text on all images
- Semantic HTML with proper headings
- Keyboard navigation

See `accessibility-requirements.md` for complete guidelines.
