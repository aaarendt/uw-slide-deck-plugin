Tags show where each step happens. Cloud providers: AWS, Google, Azure, IBM.

PROCESS: <1 week from application to account. ACCESS CloudBank for Research. Estimate Cloud Costs: Use AWS, GCP, IBM or Azure cost calculators to estimate expenses. Request an ACCESS Allocation: Create an ACCESS account and submit an allocation request for ACCESS credits. Exchange Credits for CloudBank Dollars: Exchange ACCESS credits for CloudBank dollars based on the calculator estimates. Complete Cloudbank Onboarding: Review onboarding email instructions and links. Manage Users and ACCESS Allocation: Users are centrally managed in ACCESS portal. Allocations can be extended, renewed, and supplemented. Assign Users to Commercial Cloud Accounts: Assign users to specific commercial cloud accounts in CloudBank Portal. Monitor spend and add additional commercial cloud accounts. Use Commercial Cloud Resources: Users log into commercial cloud accounts via vendor portals and manage resources and services to support their research.
