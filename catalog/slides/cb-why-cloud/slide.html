WHY CLOUD? Six things the cloud makes possible that are hard on a laptop or a fixed campus cluster. Bring compute to the data: many large research datasets are already hosted in the cloud (for example the AWS Open Data registry, Google Cloud public datasets and Microsoft Planetary Computer). Running the analysis next to the data avoids downloading terabytes to a laptop. Scale up on demand: start a GPU or large-memory machine for an intensive job, then shut it down. You pay for the hours it runs, not for hardware that sits idle. Run in parallel: launch many copies of the same job at once, such as simulations, parameter sweeps, fine-tuning runs or reinforcement learning experiments, and finish in hours instead of weeks. Use and deploy LLMs: call hosted foundation models through an API (for example Amazon Bedrock, Google Vertex AI or Azure AI Foundry), or deploy an open-weight model on your own GPU instance or managed endpoint with a serving tool such as vLLM. Share reproducible environments: package code, libraries and data access in containers, machine images or shared notebook servers, so collaborators and students all work in the same setup. Host research services: run web apps, API gateways, data portals and live model endpoints that collaborators or the public can reach.
